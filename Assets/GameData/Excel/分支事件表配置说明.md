# 分支事件表说明

一行 = 一个分支：**条件日**（第N天）的处理结果满足条件 → **生效日**（第M天，必须比条件日晚）按填的列变化，没填的列不变。改完表双击运行 Excel转Unity数据工具.py 生效。

| 列 | 用法 |
|---|---|
| 分支编号 | 唯一编号，新增从 branch_013 起（1~012 已被预填的通报批评/投诉占用，可改文案勿删） |
| 条件日 | 看这天的处理结果，填 第1天~第7天 |
| 访客1 + 结果1 | 条件：某访客处理成某结果（下拉选）；结果=正确放行/错误放行/正确拦截/错误拦截/逼走/生气 |
| 访客2 + 结果2 | 第二个条件，留空=只看访客1；几组条件之间是"并且"关系 |
| 当天状态 | 当天有访客被逼走 / 当天有访客被惹生气 / 当天拥挤（拥挤=前台同时≥2人）；留空=不要求 |
| 生效日 | 哪天变化，必须比条件日晚 |
| 新增访客 | 这天会来的访客，排在最前，逗号隔开可多个 |
| 删除访客 | 这天不来了的访客（从原日程去掉） |
| 新聊天记录 | 这天的群聊全部换成这里的内容，格式 `谁:说了什么`，分号隔开多条 |
| 新报纸标题/正文 | 这天的报纸换成新的，两格必须成对填 |
| 值班记录提示 | 这天值班记录开头多一行提示，写一句话 |

示例：第1天放走小偷→第2天小偷再来+报纸报道：条件日=第1天、访客1=visitor_014、结果1=错误放行、生效日=第2天、新增访客=visitor_014、新报纸标题/正文各填一句。
